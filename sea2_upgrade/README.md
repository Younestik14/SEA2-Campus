# SEA2 Campus · Superpack v6

Plataforma educativa offline-first para 2º de Sistemas Electrotécnicos y Automatizados.

## Incluye
- 7 módulos de segundo curso según el boletín aportado.
- Lecciones por unidad con teoría, ejemplo, práctica autocorregible y simulación.
- 16 calculadoras técnicas.
- Laboratorio PLC y diagnóstico.
- Modo Profesor local.
- Modo Examen Real.
- **Examen PRO** con banco enriquecido, categorías explícitas, dificultad, selección por blueprint, diversidad de unidades, penalización configurable, revisión completa y análisis.
- **Sesión inteligente** que prioriza errores registrados.
- Panel de rendimiento con dominio estimado, preguntas, errores y racha.
- Registro local de errores para orientar el repaso.
- Copia de seguridad/restauración de datos de localStorage.
- Proyecto técnico con impresión/PDF desde navegador.
- Planificador local.
- PWA + caché offline.
- Atajos de teclado: E = exámenes, C = cálculos, L = lecciones.

## Datos y privacidad
No requiere cuentas ni servidor. El progreso y el historial se guardan en el navegador mediante localStorage. La web es un proyecto educativo independiente y no sustituye REBT, normas UNE, documentación de fabricante ni las instrucciones del profesorado.

## Base documental
La organización de segundo curso, horas y ECTS procede del boletín oficial aportado. Los contenidos y resultados se han contrastado con la normativa curricular oficial. Las unidades didácticas, preguntas adicionales, simuladores y herramientas de estudio son una capa pedagógica propia.

## Hosting gratuito
Puedes publicar esta carpeta como sitio estático en GitHub Pages, Netlify, Cloudflare Pages o cualquier hosting estático equivalente. No necesita backend.
